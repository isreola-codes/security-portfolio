# How a web page loads

When I type a website name, my browser asks DNS to find the server's IP address. Then my computer and the server use TCP to check the connection with a three-way handshake. Next, HTTPS locks the conversation so nobody can steal my details or see what my browser is requesting. Then my browser sends an HTTP request, and the server replies with a status code (200 means successful). Finally, my browser displays the page.
